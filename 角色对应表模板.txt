# coding → ccode2.0 角色对应表
# 用途：供迁移程序读取，执行仓库成员角色迁移
#
# 使用说明：
#   1. 本文件由项目人员在映射表（角色映射表模板.xlsx）与客户确认完毕、
#      并在 ccode 中手动创建完所有自定义角色后填写
#   2. 每行代表一条 coding 权限组 → ccode 角色 的对应关系
#   3. 行的排列顺序即优先级：
#      - 第1条（最靠前）= 最高优先级（对应映射表"优先级"列中 P1 的权限组）
#      - 当用户同时持有多个权限组时，取排列最靠前的那条权限组所对应的 ccode 角色
#   4. coding 权限组名称 须与 coding 系统中的显示名称完全一致（区分大小写）
#   5. ccode 角色名称 须与 ccode 系统中的角色显示名称完全一致
#   6. 注释行以 # 开头，程序忽略空行和注释行
#   7. 字段分隔符为 | ，前后空格忽略
#
# 格式：
#   coding权限组名称 | ccode角色名称
#
# ──────────────────────────────────────────────────────────────
# 优先级顺序  coding 权限组名称          ccode 角色名称
# （第1行最高优先级，与映射表优先级 P1 对应）
# ──────────────────────────────────────────────────────────────
# 以下为示例数据，请替换为实际内容，并按优先级从高到低排列

只读访客          | 访客
代码库贡献者      | 开发者
代码库管理员      | 维护者
项目管理员        | 自定义-项目管理员
