确定要删除此 GPG 公钥吗？删除后，使用该密钥签名的历史 Commit 状态可能会变更为“未验证”。

如何生成 GPG 公钥？

请在您的本地终端执行以下命令生成 GPG 密钥对，并导出公钥上传至 CCode。

1. 生成 GPG 密钥对
gpg --full-generate-key
2. 列出 GPG 密钥以获取 Key ID
gpg --list-secret-keys --keyid-format=long

执行后找到以 sec 开头的那一行，复制其中的 GPG 密钥 ID（通常是斜杠 / 后的一段，如 rsa4096/3AA5C34371567BD2 中的 3AA5C34371567BD2）。

3. 导出公钥 (替换 [Key ID])
gpg --armor --export [Key ID]
4. 配置 Git 使用 GPG 签名
git config --global user.signingkey [Key ID]
git config --global commit.gpgsign true
开启全局校验确认

⚠ 风险提示

全局强制开启后，所有代码库都将应用 GPG 签名校验规则。强管控模式可能会阻断开发者正常的代码推送流程。

建议先使用“审计模式”进行平滑过渡。确认要继续开启吗？
